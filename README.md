# Team Task Manager

A full-stack project management app with role-based access.

## Live URL
Coming soon (Railway deployment)

## Tech Stack
- React.js (Frontend)
- Node.js + Express (Backend)
- PostgreSQL (Database)
- JWT Authentication

## Setup

### Backend
cd server
npm install
# Add .env file with DATABASE_URL and JWT_SECRET
npm run dev

### Frontend
cd client
npm install
npm start

## Features
- Signup / Login with JWT
- Create projects and manage teams
- Role-based access (Admin / Member)
- Task creation, assignment, status tracking
- Overdue task detection
- Dark themed UI
